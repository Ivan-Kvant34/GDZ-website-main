# GDZ AI Platform

Полноценный прототип сайта готовых домашних заданий с ИИ-помощником и большой БД учебников стран СНГ.

## Что реализовано

- `index.html` с удобным интерфейсом: каталог учебников, решение задач, объяснение тем.
- Backend на Express:
  - поиск по учебникам (страна / класс / предмет),
  - endpoint для решения задачи с учетом «как объясняли в школе» и фото,
  - endpoint для объяснения темы простыми словами.
- База данных PostgreSQL:
  - миграция с индексами,
  - seed-файл на **10 200** записей учебников СНГ.
- Скрипты:
  - миграция,
  - загрузка seed,
  - проверка суммарного количества строк кода (>10 000).

## Запуск

```bash
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Сайт: `http://localhost:3000`.

## Переменные окружения

Создайте `.env`:

```env
PORT=3000
DATABASE_URL=postgres://postgres:postgres@localhost:5432/gdz_ai
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

Если `OPENAI_API_KEY` не указан, используется безопасный демо-ответ.
