# Архитектура

## Компоненты

1. **Frontend** (`index.html`, `frontend/scripts`, `frontend/styles`) — UI для поиска учебников и чата.
2. **Backend API** (`backend/src`) — бизнес-логика каталога и ИИ-модулей.
3. **PostgreSQL** (`database/migrations`, `database/seeds`) — хранение учебников и справочников.

## Поток решения задачи

1. Пользователь выбирает учебник.
2. Пишет условие или отправляет фото.
3. Backend делает OCR (демо stub), добавляет школьный стиль объяснения.
4. AI-сервис формирует пошаговый ответ.
5. Результат отображается в интерфейсе.
